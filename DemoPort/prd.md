## 1. 개요

### 1.1 배경
광고·홍보·마케팅 직무는 이력서 한 장으로 역량을 보여주기 어렵다. 캠페인 기획력, 크리에이티브 감각, 성과 데이터, 커뮤니케이션 톤을 한눈에 보여줄 수 있는 **개인 프로필 웹사이트**가 필요하다.

### 1.2 목적
- 채용 담당자가 **3분 안에** 지원자의 강점과 대표 성과를 파악할 수 있게 한다.
- 포트폴리오(캠페인, 콘텐츠, 보도자료 등)를 **사례 중심**으로 정리해 실무 역량을 증명한다.
- 이메일 문의로 자연스럽게 이어지는 **연락 전환 경로**를 제공한다.

### 1.3 성공 지표 (KPI)
| 지표 | 목표 |
|---|---|
| 평균 체류 시간 | 2분 이상 |
| 포트폴리오 상세 페이지 진입률 | 방문자의 40% 이상 |
| 이메일 문의 / 이력서 다운로드 클릭 | 방문자의 10% 이상 |
| 모바일 Lighthouse 성능 점수 | 90점 이상 |

## 2. 대상 사용자

| 페르소나 | 니즈 | 핵심 행동 |
|---|---|---|
| **채용 담당자 (HR)** | 빠른 스크리닝, 기본 정보 확인 | 프로필 요약 → 이력서 PDF 다운로드 |
| **현업 팀장 / 실무 면접관** | 실제 기획·실행 역량, 성과 수치 확인 | 포트폴리오 사례 상세 열람 |
| **에이전시 / 헤드헌터** | 전문 분야, 경력 범위, 연락 수단 | 연락처 확인 → 이메일 발송 |

## 3. 범위

### 3.1 포함 (In Scope)
- 반응형 단일 웹사이트 (원페이지 + 포트폴리오 상세 페이지)
- 프로필, 역량, 경력, 포트폴리오, 연락처 섹션
- 이력서 PDF 다운로드
- 기본 SEO 및 SNS 공유용 OG 태그

### 3.2 제외 (Out of Scope, v1)
- 관리자 페이지 / CMS
- 회원가입, 로그인
- 블로그·댓글 기능
- 다국어 지원 (v2 검토)

## 4. 기능 요구사항

### 4.1 사이트 구조
```
/
├─ Hero (첫 화면)
├─ About (자기소개)
├─ Skills (핵심 역량)
├─ Experience (경력 · 학력 · 활동)
├─ Portfolio (대표 프로젝트 목록)
│   └─ /portfolio/[slug] (프로젝트 상세)
└─ Contact (연락처)
```

| ID | 요구사항 | 우선순위 |

| F5-2 | 분야 필터: 전체 / 광고 / 홍보 / 마케팅 | P1 |

상세 페이지 구조:
1. **개요** — 프로젝트명, 기간, 소속, 나의 역할, 팀 구성
2. **과제 (Challenge)** — 해결해야 했던 문제와 목표
3. **전략 (Insight & Strategy)** — 타깃 인사이트, 핵심 메시지, 채널 전략
4. **실행 (Execution)** — 주요 결과물 (광고 시안, 보도자료, 콘텐츠 등)
5. **성과 (Results)** — 정량 지표 (도달, CTR, 전환율, 기사 게재 수 등) + 정성 피드백
6. **배운 점 (Learnings)**

## 6. 디자인 가이드

- **톤 앤 매너**: 신뢰감 있는 전문성 + 마케터다운 크리에이티브 감각
- **레이아웃**: 넉넉한 여백, 큰 타이포그래피, 카드형 포트폴리오
- **컬러**: 중립 배경(화이트/오프화이트) + 포인트 컬러 1개 (CTA·태그에만 사용)
- **폰트**: 본문 Pretendard, 헤드라인은 개성 있는 디스플레이 서체 1종
- **원칙**: 결과물(비주얼)과 성과(숫자)가 가장 먼저 눈에 띄도록 정보 위계 설계

## 7. 기술 스택 (제안)

| 항목 | 선택 | 비고 |
|---|---|---|
| 구현 | HTML + CSS + Vanilla JS (v1) | 빠른 제작, 의존성 최소화 |
| 대안 | Next.js 또는 Astro | 포트폴리오가 늘어날 경우 콘텐츠 관리 용이 |
| 콘텐츠 | JSON / Markdown 파일로 분리 | 코드 수정 없이 내용 갱신 |
| 배포 | GitHub Pages 또는 Vercel | 무료, 커스텀 도메인 연결 가능 |
| 분석 | Google Analytics 4 | CTA 클릭, PDF 다운로드 이벤트 추적 |
